# Mandate 无效输入数据集验收

2026-10-20，协议 `mandate-http-r3`，种子 `0x40271015`。生成器按二十类明确无效条件，每类产生五百个不同 calldata，共一万个输入。原始调用绕过 SDK 校验，直接由本地真实合约处理。六个合法控制调用另行记录。

初次运行与同种子复验的压缩样本逐字节一致。复核脚本独立检查每个输入的无效条件、错误 selector、顺序、随机数流、源码 SHA 及编译产物。全部一万个无效输入被拒绝，合法控制调用均通过。

原始数据位于 `artifacts/m7/research/invalid-final/`，复验位于 `invalid-replay/`，审计记录为 `dataset-audit.json`。有限的构造样本用于检查明确边界，不代表枚举所有攻击，也不把同种子复验当作新的独立样本。
