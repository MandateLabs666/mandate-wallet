# M8 Local／Testnet 选择恢复

日期：2026-10-18，新加坡时间。

上次修复将“重新开始引导”理解为仅重新查看已有账户，导致第一步隐藏 Local／Testnet。后端原先也只接受一套开户配置。此次同时恢复界面选择并补齐多配置存储，避免按钮恢复后仍返回“已有配置”。

## 使用方式

第一步始终显示“创建本地体验账户”和“使用自己的测试网钱包”。已有账户另列于下方，可继续核对原账户及接入 Agent。选择新配置后，原账户、订单和 MCP 绑定保持原状。

Local 创建独立测试链，自动部署账户并准备模拟资金和一小时有限权限。不同独立测试链上的地址可能相同，配置编号、RPC、数据库与连接描述分别保存。Testnet 支持 Base Sepolia 和 Ethereum Sepolia；准备配置不会发送公共交易，部署、转入测试资金及批准权限仍由外部钱包逐项确认。

重置引导只重置当前配置的页面阶段和宿主确认。它不会新建账户、删除订单、延长授权或撤销权限。创建新配置是另一个明确操作；已有账户时，界面先说明保留范围，再经用户确认执行。

工作区及下载链接携带配置编号，各 API 请求按同一编号选择实例。没有全局“当前账户”切换，不会因另一个标签页的操作而改写 MCP 描述文件。已有扩展继续使用原连接；新配置使用自己的 Guided 包。

## 实现与验证

索引记录位于本机 `profiles.json`，每套配置有独立的 SetupEngine。创建请求先持久化唯一编号；并发或超时重试沿用原请求，不能生成第二套配置。发生中断时保留记录，不自动把未知结果当成失败重新开户。索引采用单进程锁，避免同目录被两个新版服务同时写入。

旧单配置通过独立导入记录继续访问。原 `setup.json`、profile、凭据和连接描述保留。此迁移依赖旧本地服务仍在运行；关闭节点后的链状态自动恢复尚未实现。

19 项开户测试和 26 项 Web 回归通过，覆盖新旧配置预算隔离、已付款订单与撤销状态保留、创建去重、原描述不变、按配置下载接入包、工作区选择、未知配置和未知文件参数拒绝、同源与主网拒绝，以及原有交易与恢复语义。类型检查与网页构建通过。新增测试仅使用临时本地链，不代表新版公共测试网或 Claude 原生安装已经验收。

浏览器从旧 18743 设置入口刷新后进入新版 18744，确认第一步同时显示两个选项和已有账户。取消新建不会创建配置；已有工作区可正常加载，原余额为 1.00 模拟 USDC，订单数和占用金额仍为零，会话仍已撤销且到期。

本次保留 18743 进程，因为它拥有用户原测试链和商户服务。只有旧版设置页面转至 18744；旧工作区及已安装 MCP 的依赖继续运行。正常新启动仍默认使用 18743；旧服务退出后可恢复默认端口。一次性跳转通过构建环境变量 `MANDATE_SETUP_SUCCESSOR` 配置，仅允许本机设置页，常规构建不包含该跳转。
