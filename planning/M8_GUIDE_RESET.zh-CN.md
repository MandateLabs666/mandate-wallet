# M8 引导重置与进度修复

日期：2026-10-18，新加坡时间。

后续修订：本记录的第一步设计曾仅显示已有账户，现已由 [Local／Testnet 选择恢复](M8_PROFILE_SELECTION.zh-CN.md)修正。第一步同时提供两种新配置入口及已有账户入口；本记录的重置与宿主确认规则继续适用。

用户反馈自动接入页面再次打开时已到第四步，且缺少重置入口。原界面使用 `connectionReady` 和独立 MCP 检查结果推算进度，把本机检查通过当成已完成 Agent 接入；这不能证明 Claude 或 Codex 已加载连接。

## 修改后的行为

进度条上方提供“重新开始引导”。该操作仅清除本浏览器的引导阶段、宿主选择和用户确认状态，返回第一步；账户、任务、订单、连接配置、交易 hash 与链上权限继续保留。它不部署新账户，不删除数据，也不恢复已撤销的会话。

引导分为四个页面。第一步对于已有账户显示“继续使用现有账户”；第二步核对原账户、预算、余额和会话；第三步生成或下载连接配置，用户完成宿主应用设置后确认继续；第四步核对只读结果。进度条可返回已具备条件的页面，缺少运行环境或用户确认时不能进入后续阶段。

独立 MCP 检查保持第三步的阶段不变。宿主设置完成状态由用户明确确认，页面说明它不是模型实际调用的自动证明。变更宿主、任务或会话会清除不再适用的确认。刷新保留当前引导阶段；重置后刷新仍停在第一步。本轮引入新的浏览器进度版本，旧的自动推算结果不迁移为完成状态。
