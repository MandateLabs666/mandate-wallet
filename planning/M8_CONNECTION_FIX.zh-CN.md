# M8 接入包与工作区入口修复

日期：2026-10-18。用户按向导安装后仍看到两个文件字段，Claude 报告扩展服务无法连接；工作区返回 `WEB_ROUTE_NOT_FOUND`。这是产品入口缺陷，不要求用户重新开户。

## 原因与修复

本机已安装 manifest 仍为通用 `mandate-wallet`，含 `--config` 与 `--credential-file` 两项参数。Downloads 中的包实际已使用 `--connection`，且没有 user_config；但二者具有相同名称和版本，未形成可以明确区分的扩展身份。向导生成器现为每个连接生成独立且稳定的 `mandate-wallet-guided-<摘要>` 标识，显示名称为 `Mandate Wallet · Guided <编号>`。同一连接的标识稳定，不同连接及通用手动包互不相同。包内说明也明确停用旧手动扩展、启用 Guided；不再把两个空字段解释为已完成自动配置。

工作区原链接为 `app.html?onboarding=1`，服务器将整个 URL 用作静态白名单键，因此返回 404。修订后按页面路径和明确支持的 onboarding 参数匹配，保留未知 file 参数和私有路径的拒绝。前端同时采用 `app.html#onboarding`，兼容用户正在运行的旧服务器，并在连接后切换到 overview。

## 当前用户环境

原向导进程同时持有本地链和商户，直接重启会关闭用户服务。本次没有重启该进程、停止链或重新创建数据库。仅更新磁盘上的网页、MCP 程序和生成模板：现有下载接口每次读取模板，因而也能返回 Guided 独立身份；后续新进程由修订后的生成器直接生成同样的身份。模板在构建时可重建，不作为通用发行包。

实际点击“打开钱包工作区”后，18743 页面显示原账户、1.00 模拟 USDC、采购支出 0 和占用 0，原任务与会话标识一致。当前会话在链上已撤销，不能新采购，但只读连接正常；本次没有自动重授权。独立 MCP 进程发现八项工具，mandate_get_context 的身份核对通过。

当前 Guided 本机包位于 `output/desktop/local-connection/`。它包含本机配置位置，仅供本机使用，不应作为通用源码或给其他用户的安装包。用户已选择自行安装；本次没有在 Claude 安装、启用或停用扩展，也没有发送模型消息。

## 验证与状态

新增断言覆盖通用／绑定包不冲突、不同连接身份不同、同一连接身份稳定、无必填文件字段，以及 onboarding 页面返回 HTML。原 Web 边界测试继续要求任意 file 参数返回 404。首次过宽的 query 处理导致该旧测试失败，随后缩小为显式参数支持并重新通过。
