# Mandate 实验测量规则

实验协议由 `mandate/research/protocol.json` 固定。B1 是具备本地预算检查和业务幂等记录的普通 EOA 客户端，B2 使用 Mandate 链上约束，B3 增加关联证据，B4 增加参考控制器。四组均执行同一组 HTTP 服务任务。

无效输入实验使用固定初始时间及随机种子。HTTP 签名报价和参考控制器使用正常时间检查，因此每个 trial 以当时的 wall clock 初始化独立本地链，块间隔为一秒。案例与重复序号决定组别的轮换顺序。各 trial 不共享预算、nonce 或数据库。

采购计时覆盖采购、明确恢复及交易和余额后检。完整任务计时还覆盖适用的完整证据导出和独立进程验证。部署、铸币、授权及 envelope 创建在设置阶段完成，单独记录。HTTP、签名、登记、journal、facilitator 和 controller 的阶段计时存在嵌套关系，不相加代替总时间。最小披露、篡改、删尾和 query-cap 探测在主计时结束后单独运行。

gas 与费用均从 canonical receipt 读取。采购本金、交易 gas 与服务结果分别核对。报告保留首次错误和恢复过程，最终有效不等于首次请求成功。每个具体案例重复三次，每个 HTTP 组共三十个任务。分位数采用 nearest-rank，同时列出样本量；混合案例的 P95 包含两次付款任务。

本地模拟 token、受控商户和 facilitator 的延迟不代表 Base Sepolia 或生产服务的性能。证据签名、同宿主控制器和有限样本结果均保留各自的保证边界。
