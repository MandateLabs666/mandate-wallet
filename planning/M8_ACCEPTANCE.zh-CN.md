## 已实现的用户流程

首次设置入口为 http://127.0.0.1:18743/setup.html 。源码组件可通过项目根目录的 `Start Mandate Setup.command` 启动，也可执行 `pnpm setup:build`、`pnpm setup:start`。它检查 Node、Anvil 和 MCP 构建状态，提供本地体验与外部测试网钱包两种路径。

本地体验自动准备独立链、智能账户、1.00 模拟 USDC、固定服务与一小时有限权限，总预算为 0.15 USDC，单笔上限为 0.10 USDC。公共路由为部署、测试 USDC、执行 Gas、任务授权及会话授权准备可审核交易；owner 私钥由外部钱包保管。默认不发公共交易。操作及原订单结果未知时，继续按原 hash 和 nonce 核对，不自动替换。

Claude Desktop 绑定包不再要求选择两个文件。Codex 和 Claude Code 提供新增配置预览、合并、备份、冲突拒绝及当前操作回退。手动方式保留。连接描述固定配置摘要、网络、钱包、任务和会话，改变原连接会被拒绝。
