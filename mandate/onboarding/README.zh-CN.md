# 自动开户与 Agent 接入向导

2026-10-18 接入修复：向导包的名称为 `Mandate Wallet · Guided <连接编号>`，使用与通用手动包不同的标识。请停用旧的 `Mandate Wallet` 手动扩展后再启用 Guided；自动包不会显示 Agent profile／Connection file 字段。工作区通过 `app.html#onboarding` 进入，可兼容正在运行的旧服务。修订后的服务器也支持 `app.html?onboarding=1`，继续拒绝未知的文件路径参数。

该组件为现有 Mandate 协议提供首次设置流程。系统自动准备账户、连接文件与接入配置，同时保留 Gateway、SDK 和双文件 MCP 的手动方式。当前交付是 macOS 源码版组件，尚未发行签名独立安装包。

## 启动与使用

项目依赖安装完成后，双击仓库根目录的 `Start Mandate Setup.command`。启动器检查 Node 24.2—24.x，构建扩展和网页，再打开本机设置页面。它不会自动安装软件或修改个人 Agent 配置。本地体验另需 Anvil。

也可以在仓库根目录执行：

```sh
pnpm setup:build
pnpm setup:start
```

默认入口为 http://127.0.0.1:18743/setup.html 。原有 http://127.0.0.1:18742 工作区保持独立。向导只监听本机，不向公网发布签名器或配置。保持启动终端运行；关闭终端后，本地服务将不可用。

选择“自动准备体验账户”后，系统启动独立 Anvil，部署智能账户，准备 1.00 模拟 USDC，并创建固定 ETH/BTC 数据案例的测试授权。总预算为 0.15 USDC，单笔上限为 0.10 USDC，服务价格为 0.01 USDC，授权期为一小时。公开 Anvil 测试角色仅用于本地环境。用户可在向导中撤销该体验会话；已经付款的订单仍保留。

选择自己的测试网钱包时，系统支持 Base Sepolia 和 Ethereum Sepolia。向导准备账户部署、0.15 测试 USDC 转账、0.001 测试 ETH 执行资金、任务授权及会话授权。用户在外部钱包逐笔核对并签署，组件不读取 owner 私钥。测试资金领取、登录及验证码仍由用户完成。主网请求被拒绝。2026-10-19 已通过新版向导、原生 Rabby 和 Claude Desktop 完成 Base Sepolia 开户、单次 0.01 测试 USDC 采购、原订单恢复、会话撤销及拒绝检查，见[本轮执行证据](../../competition/video/claude-desktop-base-v1/execution-evidence/run.json)。该结果不替代 Ethereum Sepolia、其他操作系统或签名独立发行的对应验收。

## 重新开始引导

进度条上方的“重新开始引导”会清除当前配置在浏览器中的引导阶段和宿主确认，返回第一步。第一步始终提供 Local 和 Testnet 两种选择，下方另列已有账户。已有账户可通过“继续使用现有账户”重新核对并接入 Agent；也可选择上方入口建立独立的新配置。账户、订单、原交易记录及链上权限继续保留。重置引导本身不会创建新钱包，也不会恢复已撤销的会话。

每个新配置使用独立目录、数据库、连接描述文件和 Guided 扩展编号。Local 另外启动独立测试链；不同本地链可能具有相同的测试合约地址，因此页面同时显示配置编号。浏览器按页面 URL 中的配置编号选择账户，切换页面不会改写已安装 MCP 的绑定。使用新配置时，应下载该配置对应的接入包，并在宿主中核对网络、钱包、任务和会话。

创建请求在发送前保存唯一编号。网络超时后重试沿用原编号，服务端不会因此再建一套账户。若创建曾经中断且结果无法确定，系统保留原记录并要求核对。关闭本地节点后自动恢复链状态仍属后续工作。

本机 MCP 检查通过不会自动跳到第四步。请先在所选 Agent 应用中完成安装或配置，再勾选确认并继续核对。此为用户确认状态，实际模型调用仍在宿主内检查。详见 [进度修复记录](../../planning/M8_GUIDE_RESET.zh-CN.md)。

## 接入 Agent

Claude Desktop 用户从当前向导下载已绑定的 `.mcpb`，在 Settings → Extensions 中安装并启用。包内包含程序和本机连接描述文件的位置，不包含令牌、私钥或数据库，无需填写两个文件字段。该包依赖生成它的本机目录，不应发送给其他用户作为通用安装包。当前 0.2.1 修复了广播后回执确认失败的处理，并提供不含凭据与签名载荷的分阶段诊断。安装更新不会延长链上授权或付款承诺。通用包继续支持手动参数；旧 0.1.0 及双文件流程保留。

Codex 和 Claude Code 用户选择配置范围后预览新增 MCP 条目，经确认再合并。Codex 使用项目 `.codex/config.toml` 或用户 `~/.codex/config.toml`；Claude Code 使用项目 `.mcp.json` 或用户 `~/.claude.json`。已有服务保留，原文件按 `.mandate-backup-<id>` 备份。检测到已有 Mandate 条目、符号链接或文件在预览后发生变化时，组件拒绝覆盖。宿主重启、项目信任和工具审批仍按宿主规则处理。

当前页面提供本次配置的回退按钮；若文件在应用后又被其他程序修改，则拒绝回退。页面刷新或进程重启后，可用原文件旁的备份人工恢复。该功能不自动删除用户原有接入配置。

“执行只读连接检查”会启动独立 MCP 进程，核对八项工具和 `mandate_get_context` 的身份。此检查不代表 Claude 或 Codex 内的模型已调用成功。请在宿主新对话中发送页面提供的只读指令，核对后再按手册第 11 步执行 ETH 采购。

## 持久化与恢复

多配置索引保存在 `.runtime/mandate-setup/profiles.json`，每套配置的开户记录、连接和会话签名器保存在 `profiles/<配置编号>/` 下。Local 的采购数据库位置由其 profile 固定。旧版 `.runtime/mandate-setup/setup.json` 继续保留；新版读取旧配置并建立独立导入记录，不改写旧描述文件。目录为 0700，敏感文件为 0600；网页和工具结果不返回令牌或签名私钥。描述文件同时绑定 profile 摘要、网络、钱包、任务和会话，运行中修改连接将导致拒绝，必须明确重启。

交易广播后立即保存 hash；结果未知时继续核对原交易的 sender、target、calldata、value、回执和区块 hash，不自动创建替代操作。采购恢复使用原订单、nonce 和数据库。授权到期不会自动延长。

重新启动会加载原记录。如果原本地 Anvil 已停止，系统保留文件并显示服务不可用，不会自动生成另一个账户冒充恢复。当前本地体验尚未提供停止节点后的链状态自动恢复；不要删除旧记录或复用其数据库启动新链。公共测试网依赖仍可访问的 RPC，并可按原记录恢复服务。完整独立安装包及本地链持久化恢复另列后续交付。

已有自有 Gateway 可通过显式启动参数接入，配置路径不通过任意网页传入：

```sh
pnpm setup:start --directory .runtime/existing-setup \
  --import-profile /ABS/PATH/case-agent.json \
  --connection-file /ABS/PATH/PRIVATE_CONNECTION.json
```

固定会话已到期或撤销时，仍可检查只读连接；向导不会以重新安装 MCP 恢复付款权限。

## 验证范围

运行 `pnpm setup:test` 检查配置合并、备份与回退、连接固定、HTTP 来源校验、本地采购恢复、撤销、外部签署交易匹配和 reorg。`pnpm typecheck` 检查类型。自动化、实际宿主应用及公共测试网分别验收，见 [M8 验收](../../planning/M8_ACCEPTANCE.zh-CN.md)。同一 OS 用户下的 stdio 连接不构成恶意宿主与本机签名器的隔离。
