# Claude Desktop 全流程演示拍摄方案

本次目标是交付不超过五分钟的真实操作视频、无旁白版本、英文字幕文件及英文配音稿。用户提供配音后，再按实际语速调整字幕并合成。当前文件均为拍摄草稿，不能作为已完成录制或 Claude 宿主验收的证据。

案例目标是让一位首次接触 Mandate 的用户，将演示账户接入 Claude Desktop，在有限预算内采购 ETH 统计样本并生成简报。随后演示原订单恢复与撤销后的新采购拒绝。样本为受控演示数据，不能称为实时市场信息。

视频从已经安装并登录的 Claude Desktop，以及已安装 Node 24、Anvil 的源码运行环境开始。画面会明确列出这些前置条件，不声称已经提供独立安装包。Local 由测试初始化程序部署及授权；公共测试网使用外部 owner 钱包签署。

录制只使用独立演示配置及新建 Claude 对话。截图或录屏不得包含个人历史对话、账户菜单、密钥、连接令牌或其他应用内容。安装扩展、启用 MCP、Claude 工具确认和系统提示按实际权限处理，不通过修改内部数据库、跳过确认或伪造模型响应完成。

等待模型响应或安装的时间可以剪短，但保留步骤顺序和必要提示。若重录，需要保留录制轮次，不能把不同账户的余额或交易画面拼接成同一笔执行。主字幕与配音必须以最终录制结果为准。
