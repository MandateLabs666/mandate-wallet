# Mandate Wallet technical documentation

The current technical documentation is the [LaTeX report](submission-2026-10-20/documents/mandate-wallet-technical-documentation.pdf). It specifies the system architecture, authorization model, x402 payment registration and settlement, durable recovery, evidence verification, research questions, evaluation and limitations.

The [editable report sources](submission-2026-10-20/documents/latex/main.tex) include native TikZ architecture, sequence and state diagrams and a BibTeX reference list. [Build instructions](BUILD_AND_DEPLOY.en.md) describe the supported source-mode setup. The [security assessment](SECURITY_SELF_ASSESSMENT.en.md) and [execution evidence](EXECUTION_EVIDENCE.en.md) provide the corresponding review and public testnet case.
