# Public source delivery

Repository: https://github.com/MandateLabs666/mandate-wallet

This repository is the current 20 October 2026 public snapshot. The original private working repository is retained separately. The initial public commit contains the reviewed working-tree source, current reports, deck, README, public execution evidence and pinned upstream manifests. It does not claim that the Oct 19 recording was generated from that later clean commit. The run retains its own file and installed-bundle fingerprints.

The local source ZIP and its SHA-256 manifest are generated from the initial public source commit. The clean reproduction report is published afterward and identifies that exact commit/archive. This avoids a circular claim that an acceptance report already existed inside the source it later tested. A later evidence-only commit may contain the reproduction report without changing the accepted code.

Snapshot selection excludes Git internals, private runtime, credentials, connection files, databases, signed transaction journals, registration forms and private proposal originals. It also excludes machine-bound MCP packages and large historical video/deck binaries. Current presentation, reports and public demo evidence remain included. The exclusion list and file hashes are saved in artifacts/competition/source-delivery/submission20261020/.

The privacy check compares archive content, including nested ZIP members, with actual local private values without printing those values. Exact pinned upstream public Anvil vectors retain their narrow existing classification. Original licenses and notices remain present. Public financial/evidence signatures required for independent verification are distinct from excluded payment-authorization signatures and raw transactions.

Clean reproduction uses a fresh source directory outside the original project. It may reuse declared verified public source archives, host toolchains and package caches. It does not copy personal runtime, keys, databases or parent workspace dependencies. Protocol, SDK, services, evidence, workspace, operations, Echo, onboarding and desktop tests retain their individual reports. The local demo performs no public transaction.

Historical rc7 and earlier source packages retain their original commits and acceptance reports. They do not cover later onboarding, graphical Claude connection or presentation changes. Consult the current reproduction report before attributing a build result to this snapshot. Publication of source is separate from official competition submission, mainnet authorization and final project gates.
